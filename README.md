# French Bistro – Restaurant Website

This is a simple and elegant website for a fictional French restaurant, built with React. It includes key sections such as a reservation form, contact page, and practical information like opening hours and location.

## Features

- Clean, modern design
- Responsive layout for all screen sizes
- Reservation form with input validation
- Contact form (currently static)
- Smooth navigation with React Router

## Technologies

- React
- React Router
- HTML5 / CSS3
- JavaScript (ES6)
